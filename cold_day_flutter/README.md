## Visual System

The app uses the Cold Day Stitch specification through Material 3 tokens in
`lib/core/theme/app_theme.dart`. Inter is specified by the design, but it is
not bundled in this repository; Flutter's platform sans-serif fallback is used
until the product provides a licensed Inter font asset or package.
